> **작성일자**: 2026-09-29

> **상태**: Completed

## 1. 배경 및 목적

공연 참여자가 진행 중인 선곡회의를 찾기 위해 공연 목록과 상세 화면을 거치지 않도록 랜딩에 바로가기를 제공합니다.

## 2. 세부 요구사항

### 2.1 사용자 시나리오

1. 공연 참여자 또는 관리자가 랜딩에 접속하면 접수 중인 선곡회의가 있는 공연의 바로가기 버튼을 봅니다.
2. 버튼을 누르면 해당 공연의 선곡회의(`/gigs/[id]/nominations`)로 이동합니다.
3. 접수 중인 선곡회의가 없거나 접근 권한이 없으면 버튼을 표시하지 않습니다.

### 2.2 비즈니스 로직 및 제약사항

- 선곡회의 날짜가 미래이거나 별도 `nomination_deadline`이 미래인 공연을 후보로 조회합니다. `nomination_deadline`이 없으면 접수 마감 없이 진행 중으로 봅니다. 관리자에게도 랜딩 바로가기는 같은 조건을 적용합니다.
- 공연 공개 범위는 `canViewGig()`로 확인합니다. 관리자는 조회 가능한 모든 공연, 그 외 사용자는 `performers.user_id`에 연결된 공연만 대상입니다.
- 대상이 여러 개면 선곡회의 날짜가 가장 빠른 공연을 선택하며 날짜가 같으면 공연 ID가 작은 항목을 선택합니다. 선곡회의 날짜가 없는 공연은 뒤에 둡니다.
- 공연 또는 참여자 조회에 실패하면 버튼을 표시하지 않습니다. 화면 자체는 계속 표시합니다.
