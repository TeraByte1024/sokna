# 공통 기능 아이콘

> 작성일자: 2026-10-05  
> 상태: 구현 완료

## 1. 목적 및 요구사항

같은 기능·상태에 같은 형태의 아이콘을 사용한다. 응답 상태는 기존 Lucide 선형 아이콘을 사용한다. 관리자 응답 표는 곡 상세의 가능 여부 배지처럼 연한 상태색 배경·테두리·둥근 직사각형으로 아이콘을 한 번만 감싼다. 공통 아이콘 자체에는 배경이나 별도 테두리를 추가하지 않는다.

## 2. 기능별 아이콘 규칙

| 의미 | 공통 아이콘 | 표현 |
| --- | --- | --- |
| 가능·참여·승인/완료 상태 | `PositiveStatusIcon` | 원 없는 Lucide `Check` |
| 불가능·불참·반려 상태 | `NegativeStatusIcon` | 원 없는 Lucide `X` |
| 미응답·미정 상태 | `UnknownStatusIcon` | Lucide `HelpCircle`, 원 안의 물음표이며 크기는 다른 상태 아이콘과 동일 |
| 해당 세션 없음 | `NotApplicableStatusIcon` | 원 없는 Lucide `Minus` |
| 메모·비고 | Lucide `MessageSquare` | 참여 신청 비고와 곡 응답 메모에 같은 메시지 아이콘 |
| 정보 수정 | Lucide `Pencil` | 공연·회원 소개·사진·곡 수정에 같은 연필 아이콘 |
| 항목 삭제 | Lucide `Trash2` | 항목 제거를 뜻하는 휴지통 |
| 저장 | Lucide `Save` | 폼 저장 버튼 |
| 계정 연동 | Lucide `Link2` | 회원 계정 연결 |

- 단순 선택 체크(`Check`), 닫기(`X`), 관리자 권한(`ShieldCheck`), 승인 대기(`Clock`) 등 서로 다른 의미는 각 기능 아이콘을 유지한다.
- 가능한 상태는 초록, 불가능은 빨강, 미응답은 중립색으로 표시한다. 선택 버튼·강조 배경에서는 대비를 위해 현재 텍스트 색상을 상속한다.
- 선곡회의 목록·곡 상세·나의 응답·관리자 응답 표의 세션 응답 상태 칩은 그림자 없이 배경색과 테두리로 표시한다.
- 아이콘만 표시하는 모바일 표는 `aria-label`과 상세 대화상자로 의미를 확인할 수 있어야 한다. 텍스트가 함께 있으면 아이콘을 장식 요소로 취급한다.

## 3. 구현 및 적용 범위

- `components/ui/status-icons.ts`에서 Lucide 상태 아이콘을 의미별 이름으로 재노출한다. 가능·불가능은 원 없는 체크·X를 사용하고 미응답만 원 안의 물음표를 사용한다. 둥근 직사각형 배지와 공통 기능 매핑을 유지한다.
- 관리자 곡 응답 표·상세 대화상자, 선곡회의 응답 등록·응답 목록·곡 상세, 공연 참가 신청·참여 상태, 계정 연결 완료·가입 완료 상태에 공통 상태 아이콘을 사용한다.
- 회원 소개와 사진 수정의 기존 `Edit2`를 `Pencil`로 통일한다.
- DB·API·권한·상태 집계 로직 변경 없음.

## 4. 검증

- 관련 화면 타입 검사, ESLint, 기존 기능 테스트 및 프로덕션 빌드로 확인한다.
- 모바일 응답 표의 제목 말줄임·아티스트 생략·가로 스크롤 없는 레이아웃과 상세 대화상자를 유지한다.
