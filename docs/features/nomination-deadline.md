# 추천곡 접수 마감 기한 명세서

> **작성일자**: 2026-09-30  
> **작성자**: SOKNA 개발팀  
> **상태**: Completed

## 1. 배경 및 목적

공연마다 추천곡 접수 마감을 선곡회의 날짜와 별개로 지정할 수 있게 합니다.

## 2. 세부 요구사항

### 2.1 사용자 시나리오

1. 관리자가 공연 정보 수정 화면에서 추천곡 접수 마감 날짜와 시간을 각각 입력하거나 둘 다 지웁니다.
2. 참여자는 지정한 마감 시각까지 추천곡을 등록할 수 있습니다. 관리자는 마감 후에도 등록할 수 있습니다.
3. 선곡회의 화면의 남은 시간과 랜딩의 진행 중 바로가기는 같은 마감 시각을 사용합니다.

### 2.2 비즈니스 로직 및 제약사항

- 마감 입력은 공연 수정 화면에만 노출하며 기존 폼 배치를 유지합니다. 날짜와 시간은 함께 입력하거나 함께 비웁니다.
- 입력값은 브라우저의 현지 날짜·시각으로 받고 절대 시각(`timestamptz`)으로 저장합니다. 다시 수정할 때 현지 날짜·시각으로 복원합니다.
- 마감값이 없으면 추천곡 접수 마감이 없으며, 선곡회의 날짜와 관계없이 참여자가 등록할 수 있습니다.
- 마감값이 없으면 선곡회의 화면에 추천 마감 정보(남은 시간·마감 안내)를 표시하지 않습니다.
- 마감 시각과 같거나 이후에는 일반 참여자의 등록 화면 접근과 서버 등록을 차단합니다. 관리자의 등록 권한은 유지합니다.
- 날짜와 시간을 모두 비워 저장하면 `nomination_deadline`을 `NULL`로 지우고 마감 기한을 해제합니다.

## 4. API / Server Action 명세

- `updateGig(formData)`는 날짜·시간을 합친 ISO 시각 또는 빈 값을 받아 유효성을 검사하고 `gigs.nomination_deadline`에 저장합니다.
- 후보곡 등록 액션은 저장 직전에 공연의 마감값을 다시 조회하여 권한을 검사합니다.
- 공통 `getNominationDeadline()` / `isNominationClosed()`는 설정된 마감 시각만 사용하며, 값이 없으면 접수를 닫지 않습니다.
