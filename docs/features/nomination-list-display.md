# 선곡회의 목록 표시 형식 명세서

> **작성일자**: 2026-10-07  
> **작성자**: Codex  
> **상태**: 구현 완료

## 1. 배경 및 목적

후보곡이 많은 선곡회의에서 제목·아티스트·작성자를 빠르게 훑어볼 수 있도록 기존 카드와 간략 목록 사이의 표시 전환을 제공한다.

## 2. 세부 요구사항

### 2.1 사용자 시나리오

1. 선곡회의에 처음 접속하면 기존 카드 형식인 **기본** 보기를 표시한다.
2. 목록 위의 **목록 보기: 기본 / 간략** 버튼에서 간략을 선택하면 각 곡을 `곡 제목 - 아티스트 · 세션별 내 응답 칩 | 작성자` 순서로 표시한다. 응답 칩은 곡 제목 오른쪽, 작성자 구분선 바로 앞에 배치한다. 작성자는 충분히 넓은 화면에서 기수와 이름을 함께 표시하고 모바일·좁은 목록에서는 구분자와 함께 숨긴다.
   - 사용자가 선택한 Lucide 아이콘 조합 `LayoutList`(기본) / `List`(간략)을 사용한다. 모바일에서는 아이콘만 표시하고 `sm` 이상에서는 아이콘과 기본·간략 레이블, 목록 보기 캡션을 함께 표시한다.
3. 기본을 선택하면 썸네일·세션·악보·내 응답·어필을 포함한 기존 카드로 돌아간다.
4. 두 형식 모두 곡을 클릭하거나 키보드 Enter/Space로 선택하면 기존 상세 서랍을 열고 해당 곡의 변경 강조를 해제한다.

### 2.2 비즈니스 로직 및 제약사항

- 기존 공연 참여자·관리자 접근 권한과 곡 수정·응답 권한을 유지한다.
- 표시 형식 전환은 검색어, 세션·응답·악보 필터, 변경 곡 필터, 등록순 정렬, 확인 상태를 변경하지 않는다.
- 간략 보기에서는 썸네일·필요 세션·악보·어필·상세보기 문구·신규/수정 배지를 생략한다. 신규·수정 곡의 기존 테두리와 좌측 색상 강조는 유지하고 스크린리더용 상태 문구를 제공한다.
- 내 응답은 기본·간략 보기 모두 **세션별**로 동일한 디자인을 사용한다. 기존 상태 칩의 24px 높이·둥근 테두리·여백·굵은 글자·상태색을 유지하고 내용은 `{공통 상태 아이콘} {세션명}`으로 표시한다. 가능은 초록 체크, 불가능은 빨강 X, 미선택은 회색 물음표이며 상태 문구는 칩 본문에서 생략한다. 툴팁·접근성 레이블에는 세션명과 상태를 함께 제공한다.
- 세션 응답 칩에는 그림자 효과를 적용하지 않는다. 기본·간략 목록의 세션별 응답과 `내 응답 미선택`, 곡 상세의 참여자 응답 및 나의 응답 상태 칩에 같은 규칙을 적용한다.
- 배정 세션·추천 보컬·Local Custom 규칙에 따라 응답 가능한 모든 세션을 공통 세션 정렬 순서로 표시한다. 미저장·미정 응답도 미선택 칩으로 표시한다. 해당 공연의 참여자가 아닌 관리자와 응답 가능한 세션이 없는 곡은 세션별 응답 칩을 생략한다. 기본 보기의 세션별 응답이 없는 경우 기존 `내 응답 미선택` 안내를 물음표 아이콘과 함께 유지한다.
- 아티스트가 없으면 제목 뒤 구분자를 생략하고, 작성자가 없으면 `동아리 부원`을 표시한다.
- 작성자와 `|` 구분자는 화면 폭이 768px 이상이면서 해당 곡 카드 폭이 640px 이상일 때만 표시한다. 모바일뿐 아니라 큰 화면의 좁은 목록에서도 숨기도록 CSS 컨테이너 쿼리를 사용한다. 기본 보기의 작성자는 기존 방식으로 유지한다.
- 긴 제목·이름은 말줄임하여 가로 넘침을 방지한다. 응답 칩 영역은 행 폭의 최대 50% 안에서 줄바꿈하고 긴 세션명은 말줄임한다. 상세 서랍에서 전체 정보를 확인할 수 있다.
- 선택은 현재 패널의 클라이언트 상태로 관리하며 새로고침 또는 재접속 시 기본 보기로 시작한다. DB나 브라우저 저장소에 저장하지 않는다.

## 5. UI / UX 설계

- 라우트: `/gigs/[id]/nominations`
- `components/nominations/nomination-panel.tsx`: 기본/간략 상태 및 접근 가능한 분할 버튼을 관리한다. 모바일·데스크톱 모두 검색 행, 펼친 필터 및 적용된 필터 요약 다음 독립 행에 전환 버튼을 오른쪽 정렬로 제공한다.
- `NominationCard`: 표시 형식에 따라 기존 카드 본문 또는 낮은 높이의 요약과 세션별 내 응답 칩을 렌더링한다. 두 보기 모두 관리자 표와 같은 `getEligibleSessionsForUser`로 응답 가능 세션을 계산하고 공통 `NominationResponseChip`으로 가능·불가능·미선택을 표시한다. 간략 카드에 `container-type: inline-size`를 적용해 작성자 표시를 카드 폭에 따라 결정한다. 클릭·키보드 이벤트 및 변경 강조는 공통으로 유지한다.
- 버튼의 선택 상태는 `aria-pressed`로 알리고 아이콘만 표시할 때도 `aria-label`과 `title`에 기본 보기·간략 보기를 제공한다. 아이콘은 장식 요소로 처리하며 곡 행에는 키보드 포커스 표시를 제공한다.
