# 03. 공연 추가 페이지 (`/gigs/new`) [관리자 전용]

## 1. 개요 및 접근 권한
- **URL 경로**: `/gigs/new`
- **대상 사용자**: **관리자(Admin) 전용**
- **목적**: 새로운 공연 일정을 생성하고, 해당 무대에 참가할 동아리 회원들을 검색하여 세션 참여자(Performer)로 등록 및 파트 지정.

## 3. 사용자 인터랙션 및 UX 흐름 (Step-by-Step)

1. **권한 인가 검사 (Access Control)**:
   - 비관리자 또는 비로그인 사용자가 직접 URL로 접근할 경우, 폼 대신 **접근 제한 카드**가 렌더링됩니다:
     - 문구: `"공연 추가는 관리자 권한이 필요합니다."`
     - 버튼: `[로그인]` (`/auth/login`), `[목록으로]` (`/gigs`)
2. **공연 수정과 100% 동일한 통합 폼 (`GigForm`)**:
   - 공연 등록과 공연 수정 페이지가 단일 공통 컴포넌트(`GigForm`)를 공유하여 양식과 스타일, 기능이 완벽히 일치합니다.
   - **포스터 & 제목/부제목 레이아웃**: 공연 상세 페이지와 동일한 시각적 위계를 갖추기 위해 데스크톱 기준 좌측에 포스터(규격 1:1.41), 우측에 공연 제목 및 공연 부제목을 나란히 배치(`포스터 | 제목`, `포스터 | 부제목`). 모바일에서는 포스터가 상단에 아담하게 위치하고 아래로 제목/부제목이 이어집니다.
   - **티켓 예매 가격 (사전예매 / 현장예매)**: 공연 부제목 밑에 사전예매 가격(`advance_ticket_price`)과 현장예매 가격(`door_ticket_price`)을 입력할 수 있는 2열 텍스트 필드를 제공합니다. 한국 원화(KRW, 정수) 단위로 천 단위 쉼표 포맷팅 및 접미사(`원`)가 자동 적용됩니다.
   - **포스터 이미지 등록/수정**: Supabase Storage `gigs/posters/`에 직접 업로드되며 실시간 썸네일 미리보기가 제공됩니다. **드래그 앤 드롭(Drag & Drop)** 및 파일 변경/삭제가 가능합니다.
   - **공연 일시 / 선곡회의 일시**: 공연 일시(필수), 선곡회의 일시(선택, 2열 배치).
   - **공연 장소 / 선곡회의 장소**: 공연 및 선곡회의가 열리는 장소 입력.
   - **공개 여부 (기본값: 비공개)**: `비공개`(링크/부원 전용) / `공개`(전체 방문자 노출) 선택 카드. 기본값은 `비공개`로 설정되어 신규 공연 작성 중 의도치 않은 외부에의 조기 노출을 방지합니다.
   - **SETLIST 관리 (총 n곡)**:
     - 공연 생성 시에도 곡 목록을 바로 등록할 수 있으며, 섹션 제목은 `SETLIST 관리 (총 n곡)`으로 표시됩니다.
     - **세션 표시 순서 일괄 및 개별 편집**: `[세션 순서 설정]` 다이얼로그(`SessionOrderDialog`)를 통해 전체 곡의 세션 종류 표시 순서(기본 밴드 순서, 리듬 섹션 우선, 가나다순 프리셋 및 커스텀 세션 추가/상하 이동)를 일괄 편집 및 적용할 수 있으며, 각 곡 내에서도 미니 좌우 이동 버튼(`<`/`>`)으로 개별 세션 슬롯 순서를 즉시 조정할 수 있습니다.
     - **인라인 세션 칩 & 확장 입력 / 세션 삭제 확인**: 불필요한 레이블을 제거하고 수평 인라인 칩(`[세션명 | 이름 ✕ ... | + | 🗑]`)으로 구성됩니다. 각 세션의 인원 추가는 평소 콤팩트한 `+` 버튼으로 접혀 있다가 클릭 시 텍스트 필드로 확장되어 부원 자동완성 검색 및 직접 입력을 지원합니다. 또한 `[+ 세션 추가]` 버튼 역시 클릭 시 인라인 텍스트 필드로 확장되어 새 세션명을 입력하여 바로 추가할 수 있습니다(세션 추가 시 불필요한 토스트 미노출, 자주 쓰는 세션 드롭다운 폐기). 세션 칩의 `🗑` 삭제 버튼 클릭 시 확인 다이얼로그(배정 인원 안내 및 삭제 확인)를 표시하여 오동작을 방지합니다.
     - **비연동(텍스트) 원칙**: 셋리스트의 세션 인원은 텍스트로만 저장되며, 실제 회원 정보를 연동하거나 공연자 명단에 더미 performer를 생성하지 않습니다.
     - **엑셀에서 공연자 / 셋리스트 불러오기**: 엑셀 표 복사 후 일괄 등록 및 스마트 Conflict 해결을 지원합니다.
    - **공연자 명단 및 스마트 연동 / 다중 세션 / 정렬**:
      - 부원 검색창 또는 엑셀 명단 일괄 붙여넣기를 통해 추가.
      - **프로필 컬럼 삭제 및 정렬 기능**: 프로필 사진 열을 삭제하여 테이블을 슬림화하고, 기본 정렬(이름 가나다순 > 기수순) 및 헤더/드롭다운을 통한 정렬 전환(기수순, 등록순)을 제공합니다.
      - 엑셀 붙여넣기 시 `users` 테이블을 자동 조회하여 일치하는 회원은 즉시 자동 연동, 동명이인/미등록은 미연동으로 등록.
      - 미연동 회원은 각 행의 `[🔗 연동]` 버튼을 클릭하여 `PerformerMappingDialog`를 통해 수동으로 부원 계정과 매핑 가능.
      - **다중 세션 뱃지 지원**: 공연자 1명당 여러 세션을 중복 지정할 수 있으며(`[보컬 ✕] [기타 ✕]`), `[+ 추가]` 팝오버를 통해 프리셋 및 직접 입력으로 세션 종류를 자유롭게 추가/삭제 가능.
3. **저장 및 등록 완료 (`createGig` Server Action)**:
   - 미연동 인원도 DB에 더미 상태(`user_id = null, name = '...'`)로 온전히 영구 저장되므로 누락 없이 안전하게 등록됩니다.
   - 서버 사이드에서 `gigs` 테이블에 기본 정보 삽입, `performers` 테이블에 연동/더미 공연자 N:M 일괄 삽입, `setlists` 테이블에 입력된 곡 목록 일괄 삽입.
   - 저장이 완료되면 생성된 공연 상세 페이지(`/gigs/:id`)로 자동 이동하며 토스트 알림을 표시합니다.
4. **페이지 이탈 방지 확인 팝업 (`LeaveConfirmModal` 및 `beforeunload`)**:
   - 폼 작성 중(`isDirty`) 사용자가 상단 뒤로가기 링크, 하단 [취소] 버튼, 사이트 헤더/푸터 링크를 클릭하거나 브라우저 탭 닫기/새로고침을 시도할 경우, 작성 중인 내용이 유실되지 않도록 확인 팝업("페이지를 벗어나시겠습니까?")을 표시하여 이탈을 방지합니다.

## 4. UI 상태 (States)

| 상태 | 화면 표시 및 처리 |
| :--- | :--- |
| **로딩 (Loading)** | 관리자 권한 확인 중 실제 폼 너비에 맞춘 뒤로가기·제목·기본 정보(포스터/입력칸) 스켈레톤 표시. 스크린리더에는 로딩 문구를 알리고 움직임 줄이기 설정 시 점멸을 멈춤 |
| **비인가 상태 (Non-admin)** | `접근 제한` 카드 표시 (폼 노출 안 됨) |
| **작성 중 (Normal)** | 입력 필드 활성화, 포스터 미리보기, 셋리스트 에디터, 공연자 테이블 및 미연동 뱃지 |
| **제출 중 (Pending)** | 제출 버튼 비활성화 및 로딩 스피너 작동 |
| **검증 실패 (Validation)** | 에러 메시지 표시 (예: `"공연 제목은 필수입니다."`) |
