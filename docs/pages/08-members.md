# 08. 역대 부원 소개 페이지 (`/members`)

## 1. 개요 및 접근 권한
- **URL 경로**: `/members`
- **대상 사용자**:
  - **조회**: 모든 사용자 (방문자, 회원, 관리자)
  - **부원 추가/수정/삭제**: **관리자(Admin) 전용**
- **목적**: 동아리 창립 이래 활동한 역대 선후배 부원 명단을 기수별로 정리하여 열람하고, 관리자가 부원 데이터를 관리.
- **로딩**: 관리자 권한과 공개 부원 목록을 병렬 조회하며, 공연·사진첩 목록과 공통 `LoadingIndicator`를 표시합니다.

## 3. 사용자 인터랙션 및 UX 흐름

1. **기수별 자동 그룹화**:
   - `users` 테이블에서 `generation IS NOT NULL`인 부원 데이터를 조회하여 최신 기수부터 내림차순으로 그룹화하여 표시합니다.
2. **관리자 CRUD 인터랙션**:
   - `[+ 부원 추가]` 클릭 시 모달 오픈: 이름, 기수, 파트 입력 후 `addMemberAction` 호출.
   - 각 카드 우측 `[수정(✏️)]` 클릭 시 기존 값 자동 채움 및 `updateMemberAction` 호출.
   - `[삭제(🗑️)]` 클릭 시 확인 후 `deleteMemberAction` 호출.
   - 작업 완료 시 `revalidatePath("/members")`를 통해 최신 명단으로 즉시 갱신.
