# 16. 공연 관리 (`/admin/gigs`, `/admin/gigs/[id]`)

## 접근과 화면

- 관리자 전용. 공연 목록에서 공연명, 일자, 공개 범위, 확정 참여자 수, 승인 대기 건수, 비고 건수를 표시한다.
- 공연을 선택하면 `performers`의 확정 참여자 이름·기수·담당 세션을 확인한다. 계정에 연결되지 않은 공연자는 저장된 표시 이름을 사용한다.
- 공연자별 곡 응답 현황에서 세션을 먼저 선택한 뒤 `응답현황 공연자 순서` 목록에서 한 명 또는 여러 명을 체크하고 위·아래 버튼으로 순서를 정한다. 선택한 사람만 1부터 번호를 부여하며 한 명만 선택하면 첫 슬롯에 표시한다. 해당 세션에 응답 가능한 곡만 표시하며 곡 제목·아티스트는 한 줄 말줄임으로 표시한다. 응답은 모든 화면에서 한 줄 5명씩 배치한다. 현재 선택 안에서는 곡마다 번호가 같고, 선택한 사람 중 해당 곡의 세션에 참여하지 않는 자리는 비워 둔다. 컬럼명 옆 도움말 dialog에서도 현재 선택 번호를 확인한다. 데스크톱 행은 곡 상세로, 모바일 행은 응답 상세 dialog로 이동한다. 모든 화면에서 메모가 있을 때만 아이콘을 표시하고 클릭 시 응답 상세 dialog를 연다. 상세 규칙은 [공연자별 곡 응답 현황](../features/admin-performer-song-responses.md)을 따른다.
- 공연자 관리 표에 비고 컬럼을 두고, 같은 공연의 `gig_rsvps.note`를 참여자의 회원 ID로 연결해 읽기 전용으로 표시한다. 선곡회의 응답 메모와 같은 메시지 아이콘·연한 배경·둥근 테두리 칩을 사용하고 긴 내용은 말줄임 및 툴팁으로 표시한다. 비고가 없거나 계정 미연동이면 `-`, 신청 조회 실패 시 `조회 실패`로 표시한다. 별도 신청 비고 표는 제거한다.
- 이미 연동된 참여자는 `연동됨` 상태만 표시하며 연동 변경·해제 버튼을 제공하지 않는다. 미연동 참여자는 기존 연동 버튼을 유지한다.
- 상단 메뉴와 본문 섹션은 `기본 정보 → 선곡회의 곡 목록 → SETLIST 관리 → 공연자 관리 → 공연자별 곡 응답 현황` 순서로 표시한다. 선곡회의 곡 목록은 등록순으로 제목·아티스트를 한 줄에 표시하며 행 전체를 눌러 곡 상세로 이동할 수 있다. 별도 선곡회의 열기 버튼을 제공한다.
- 기본 정보·SETLIST·공연자 명단은 같은 수정 폼에서 저장한다. 상단의 각 섹션 바로가기로 이동하며 저장 성공 후 같은 관리자 공연 페이지를 갱신한다. 기존 확정 참여자 조회 표는 공연자 관리 폼으로 대체한다. 대기 신청이 있으면 승인 화면으로 이동할 수 있다.

## 모바일 참여자 관리

- `sm` 미만에서는 5개 공연별 바로가기를 기존 관리자 drawer 안에 같은 순서로 표시하고 본문 바로가기 버튼은 숨긴다. 같은 페이지 스크롤 이동은 이탈 확인을 띄우지 않는다.
- 참여자 표에 이름·기수·세션·비고를 표시한다. 기수는 모바일에서 좌우 여백을 줄여 표시하고, 번호·연동·삭제 열과 세션 인라인 추가·삭제 버튼을 숨긴다. 비고는 있을 때만 메시지 아이콘으로 표시하고 상세 대화상자에서 전체 내용을 확인한다. 세션 추가 툴바 버튼도 숨긴다.
- 행 또는 이름 버튼을 누르면 이름·기수·계정·전체 비고를 조회하고 담당 세션을 편집하는 상세 대화상자를 연다. 적용은 폼에 반영하며 ‘수정 완료’로 최종 저장한다. 미연동 참여자는 상세 대화상자에서 기존 계정 연동 화면으로 이동한다. 연동된 참여자에게 변경·해제 버튼을 제공하지 않는다.
- 데스크톱 삭제 버튼과 상세 대화상자의 공연자 삭제는 모두 삭제 확인 대화상자를 연다. 취소·Escape는 명단을 유지하고 삭제 확인 시에만 해당 행을 폼에서 제외한다. 최종 DB 반영은 기존 ‘수정 완료’ 저장을 따른다.
- 대화상자는 브라우저 기본 modal dialog의 포커스 제한·Escape 닫기를 사용하고 작은 화면에서 세로 스크롤을 지원한다.
- 모바일 곡 응답 표는 가로 스크롤 없이 제목 말줄임·아티스트 생략·응답 색상 아이콘·메모가 있을 때만 아이콘 표시를 사용한다. `세션 전체` 선택을 제거하며 행 터치로 전체 응답 상세 대화상자를 연다. 요약은 이름 없이 `M곡 중 N곡 응답`으로 전체 후보곡 수와 응답 완료 곡 수를 표시한다. 집계 규칙은 [응답 현황 명세](../features/admin-performer-song-responses.md)를 따른다.

## 데이터와 상태

- 응답 현황 세션 드롭다운은 관리자 회원 관리와 같은 공통 DropdownMenu 기반 단일 선택 UI를 사용한다. 기본 세션·별칭을 먼저 표시하고 공연에 미배정된 로컬 커스텀 세션은 마지막에 표시한다.

- 관리자 레이아웃에서 계정 ID 기반 권한을 확인한다. `gig_rsvps`의 비고는 관리자 또는 작성자만 조회할 수 있다는 기존 RLS를 유지한다.
- 목록·상세 조회에 실패하면 오류를 표시한다. 확정 참여자나 비고가 없으면 각각 빈 목록 안내를 표시한다.
- 직접 배정된 공연자에게는 RSVP 비고가 없을 수 있다. 이전 `ignore` 동작으로 삭제된 과거 신청은 복구하지 않는다.
