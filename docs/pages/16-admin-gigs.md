# 16. 공연 관리 (`/admin/gigs`, `/admin/gigs/[id]`)

## 접근과 화면

- 관리자 전용. 공연 목록에서 공연명, 일자, 공개 범위, 확정 참여자 수, 승인 대기 건수, 비고 건수를 표시한다.
- 공연을 선택하면 `performers`의 확정 참여자 이름·기수·담당 세션을 확인한다. 계정에 연결되지 않은 공연자는 저장된 표시 이름을 사용한다.
- 같은 공연의 `gig_rsvps.note` 중 공백이 아닌 비고를 한 표에 모은다. 신청자, 참여·불참·미정 의사, 검토 상태, 신청 세션, 비고를 함께 표시한다. 승인·반려된 신청도 보존된 기록으로 표시한다.
- 공연 상세에는 관리자 전용 공연 정보 수정 버튼을 두어 `/gigs/[id]/edit`로 바로 이동한다. 대기 신청이 있으면 승인 화면으로 이동할 수 있다.

## 데이터와 상태

- 관리자 레이아웃에서 계정 ID 기반 권한을 확인한다. `gig_rsvps`의 비고는 관리자 또는 작성자만 조회할 수 있다는 기존 RLS를 유지한다.
- 목록·상세 조회에 실패하면 오류를 표시한다. 확정 참여자나 비고가 없으면 각각 빈 목록 안내를 표시한다.
- 직접 배정된 공연자에게는 RSVP 비고가 없을 수 있다. 이전 `ignore` 동작으로 삭제된 과거 신청은 복구하지 않는다.
