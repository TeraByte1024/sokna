# 04. 선곡 회의 및 셋리스트 페이지 (`/gigs/[id]/nominations`)

## 1. 개요 및 접근 권한
- **URL 경로**: `/gigs/[id]/nominations` (기존 `/setlists` 접속 시 자동 리다이렉트)
- **대상 사용자**:
  - **화면 접근 권한**: **해당 공연의 참여 세션원(Performer) 및 관리자(Admin)** 전용
    - 비로그인 사용자: 로그인 페이지(`/auth/login?redirect=/gigs/[id]/nominations`)로 즉시 리다이렉트
    - 비참여 일반 부원: "공연 참여자 전용 화면입니다" 안내 카드 및 공연 상세 바로가기 제공
  - **후보곡 등록 권한**: **해당 공연의 참여 세션원(Performer) 및 관리자**
  - **후보곡 삭제 권한**: 선곡회의 후보곡(`order_num = 0`)은 **곡 등록 본인 또는 관리자** 가능 (공연 정보 확정 셋리스트는 오직 관리자만 삭제/수정 가능)
- **목적**: 특정 공연에 참여하는 세션원들이 후보곡을 등록하고, 필요 파트(보컬, 악기) 및 악보 유무, 유튜브 음원 링크를 공유하며 팀원들과 편성을 조율.
- **초기 로딩**: 서버에서 로그인·관리자/참여자 권한을 확인한 뒤 공연, 후보곡, 공연자, 마지막 조회 시점을 조회하여 `NominationPanel`의 초기 데이터로 전달합니다. `Suspense`는 서버 조회 중 공통 로딩 표시를 보여주며, 클라이언트에서 같은 목록을 다시 조회하지 않습니다. 곡 상세 `NominationDrawer` 코드는 처음 열 때 불러옵니다.

### 2.1 선곡회의 상단 정보

- 상단은 기존 안쪽 여백(`p-6`, `sm:p-8`)과 둥근 카드 형태를 유지하되 모바일에서는 숨겨진 데스크톱 추천 버튼 영역이 빈 공간을 차지하지 않게 하며, 은은한 primary 색조 배경·테두리와 부드러운 그림자로 아래 후보곡 카드보다 살짝 강조하고 제목은 `{공연 제목} 선곡회의` 한 줄로 표시합니다. 공연 제목이 길면 말줄임표(ellipsis)로 줄이고 `선곡회의`는 항상 보이게 합니다. 상단 경로의 공연 제목에도 말줄임표를 적용합니다. 별도 부제목, 내 참여 세션, D-Day 칩, 공연일과 공연 장소는 표시하지 않습니다.
- 데스크톱의 `곡 추천하기` 버튼은 후보곡 추천 마감 정보가 있는 행의 하단에 맞춰 배치합니다. 정보 영역의 `선곡회의` 레이블 없이 회의 날짜와 장소를 아이콘 및 구분선과 함께 나란히 표시하고, 오른쪽에 정렬한 시계 아이콘·`추천 마감까지` 문구·남은 기간도 같은 행에 한 줄로 표시합니다. 장소가 길면 말줄임표로 줄여 이 행을 유지합니다. 모바일과 데스크톱 모두 날짜를 `2026년 10월 9일 금요일` 형식으로 표시합니다. 모바일에서는 `선곡회의` 정보 레이블을 숨기고 달력 아이콘과 전체 날짜를 첫째 행, 위치 아이콘과 `meeting_location`을 둘째 행에 같은 높이로 맞춰 표시하며 장소가 길면 텍스트 시작 위치에 맞춰 줄바꿈하고, 시계 아이콘과 `추천 마감까지` 문구·남은 기간 전체를 한 줄로 셋째 행에 표시합니다. 세 아이콘의 시작 위치와 크기를 맞춥니다. 날짜 또는 장소가 없거나 공백이면 행을 생략하지 않고 각각 아이콘 뒤에 `날짜 미정`, `장소 미정`을 표시합니다. 장소와 `장소 미정`은 모바일·데스크톱 모두 날짜처럼 기본 글자색으로 표시합니다.
- `추천 마감까지` 뒤에 표시하는 남은 시간은 가장 큰 단위 하나만 표시합니다. 1일 이상은 `n일 남았어요`, 1시간 이상은 `n시간 남았어요`, 그보다 짧으면 `n분 남았어요`로 표시하며 1분 미만은 `1분 남았어요`로 표시합니다. `추천 마감까지`와 남은 기간은 같은 글자 크기로 표시하며, 숫자와 단위만 굵게 표시하고 `남았어요`는 보통 굵기로 표시합니다. 마감 후에는 모바일·데스크톱 모두 정보 행에 `추천곡 접수가 마감되었습니다`만 표시하며, 제목 위에 별도의 `추천 마감` 칩은 표시하지 않습니다.

### 2.2 후보곡 검색 및 필터

- 후보곡 목록 위의 검색창과 필터 버튼은 별도 카드로 감싸지 않습니다. 펼친 세션·응답·악보 필터 영역만 둥근 테두리와 은은한 배경·안쪽 여백·약한 그림자의 박스로 묶어 검색 행과 구분합니다.
- 검색 입력창, 필터 버튼과 개별 필터 선택 요소의 자체 테두리는 유지합니다. 세션·응답·악보 캡션은 콜론 없이 좁은 동일 폭으로 맞춰 모바일과 데스크톱 모두 각 선택 버튼 그룹과 같은 행에 가깝게 표시하고, 세 그룹 모두 둥근 테두리·연한 배경과 선택된 버튼의 기본 배경을 사용하는 동일한 분할 버튼 스타일을 적용합니다. 좁은 화면에서는 버튼 그룹 내부만 가로 스크롤합니다. 활성 필터의 초기화 버튼은 별도 행 오른쪽에 배치합니다. 변경 사항 안내가 있으면 해당 안내 배너의 강조 스타일도 유지합니다.

---

### 2.3 후보곡 목록 표시 형식

- 검색·필터 영역 다음 독립 행 오른쪽에 기본 보기 `LayoutList` / 간략 보기 `List` 아이콘 분할 버튼을 표시합니다. 모바일에서는 아이콘만 표시하고 `sm` 이상에서는 아이콘 옆에 기본·간략 레이블과 목록 보기 캡션을 표시합니다. 아이콘만 표시해도 버튼의 접근성 이름과 툴팁은 기본 보기·간략 보기이며 선택 상태는 `aria-pressed`로 알립니다. 최초 접속·새로고침 시 기존 카드 형식인 기본 보기를 선택합니다.
- 간략 보기에서는 각 후보곡을 `곡 제목 - 아티스트 · 세션별 내 응답 칩 | 기수 작성자` 순서로 표시합니다. 칩은 오른쪽 작성자 구분선 바로 앞에 배치하며 기본 보기에도 같은 `{아이콘} {세션명}` 디자인을 적용합니다. 가능은 초록 체크, 불가능은 빨강 X, 미선택은 회색 물음표입니다. 응답 가능한 모든 세션을 공통 세션 순서로 표시하고 미저장·미정도 미선택 칩으로 표시합니다. 툴팁·접근성 레이블로 세션명·상태를 확인하고 참여자가 아닌 관리자 및 응답 가능한 세션이 없는 곡에서는 세션별 칩을 생략합니다. 썸네일, 필요 세션·악보, 어필 및 신규/수정 배지는 간략 보기에서 생략하며 변경 곡의 테두리와 좌측 색상 강조를 유지합니다.
- 모바일·좁은 목록에서는 작성자와 `|` 구분자를 생략합니다. 작성자는 화면 폭 768px 이상 및 카드 폭 640px 이상일 때만 표시하며 기본 보기의 작성자는 기존 방식을 유지합니다. 긴 제목·작성자는 말줄임하고 여러 응답 칩은 행 폭의 최대 50% 안에서 줄바꿈합니다. 아티스트가 없으면 제목 뒤 구분자를 생략하고 작성자가 없으면 넓은 화면에서 `동아리 부원`을 표시합니다.
- 전환 시 검색·필터·등록순 정렬·확인 상태를 유지합니다. 두 형식 모두 클릭 또는 Enter/Space로 기존 곡 상세 서랍을 열 수 있습니다. 선택은 현재 패널 상태로만 관리합니다.
- 상세 요구사항은 [선곡회의 목록 표시 형식](../features/nomination-list-display.md)을 따릅니다.

## 3. 사용자 인터랙션 및 UX 흐름 (Step-by-Step)

### 3.1 마감 타이머 계산 (Deadline Timer)
- 공연별 `nomination_deadline`이 있으면 이를 곡 추천 최종 마감 시각으로 사용합니다. 값이 없으면 접수 마감 기한이 없습니다.
- 별도 마감 시간이 없는 공연은 선곡회의 상단의 추천 마감 정보 행을 모바일·데스크톱 모두에서 숨기며, 참여자의 추천곡 등록은 계속 허용합니다.
- 마감 전: 남은 시간의 가장 큰 단위 하나를 분마다 갱신하며 `[+ 후보곡 추천하기]` 버튼 활성화.
- 마감 후: `"추천곡 접수가 마감되었습니다"` 안내로 전환되며 일반 참여자는 `[+ 후보곡 추천하기]` 버튼이 비활성화됨. **관리자(Admin)에게는 마감 이후에도 버튼이 비활성화되지 않고 상시 추천 가능**.
- 상단·빈 목록·모바일 추천 버튼은 비활성 상태에서 이동 링크 없이 실제 `disabled` 버튼으로 렌더링하여 마우스 및 키보드로 등록 화면에 진입할 수 없습니다.
- 마감 판정은 화면·등록 페이지·저장 액션이 동일한 공통 유틸리티를 사용하며, 마감 시각 포함 이후 또는 회의 날짜가 없거나 유효하지 않은 경우 일반 참여자의 신규 추천을 차단합니다.
- 모바일 화면에서는 텍스트 버튼 대신 우측 하단에 원형 `+` 플로팅 버튼을 고정 표시하며, 공통 하단 내비게이션과 기기 안전 영역 위에 배치합니다.

### 3.2 후보곡 등록 전용 페이지 (`/gigs/[id]/nominations/new`)
1. 선곡 회의 목록 또는 빈 상태에서 `[+ 후보곡 추천하기]` 클릭 시 모달이 아닌 **독립 전용 페이지(`/gigs/[id]/nominations/new`)**로 이동합니다.
   - 일반 참여자가 접수 마감 후 등록 URL로 직접 접근하면 서버에서 선곡회의 목록으로 돌려보내며 등록 폼을 표시하지 않습니다.
   - 마감 전에 열어 둔 폼도 제출 시 서버에서 마감을 다시 검사하여 등록을 차단합니다. 관리자에게는 마감 예외를 유지합니다.
2. 곡 제목, 아티스트 입력.
3. **악보 보유 여부 및 악보 메모**:
   - '악보 있어요' / '악보 없어요' 세그먼트 버튼 선택.
   - 바로 아래 악보 메모 입력 필드(Textarea, 넓은 폭)에 키 정보, 보유 파트, 악보 링크 등을 멀티라인으로 자유롭게 입력 가능.
4. **필요 세션 구성**:
   - 신규 등록 시 기본값으로 **기타 (1), 베이스 (1), 드럼 (1)**이 기본 선택되어 제공됨.
   - 보컬(남), 보컬(여), 기타, 베이스, 드럼, 건반 등 카테고리 칩 클릭으로 수량 증감.
   - `직접 입력` 인라인 필드에서 Enter를 누르거나 포커스를 다른 요소로 옮기면 입력한 커스텀 세션을 추가합니다. 앞뒤 공백을 제거하고 빈 값은 추가하지 않으며, 추가 후 입력을 비워 Enter 뒤 포커스 이동으로 같은 입력이 중복 추가되지 않도록 합니다. 곡 추천 작성·수정 페이지에 공통 적용합니다.
   - 인풋 필드에서 Enter 입력 시 자동 폼 제출이 방지되어 편안한 텍스트 입력 지원.
5. **추천 보컬 지정 (`RecommendedVocalSelector`)**:
   - 컴팩트 모드: 선택된 보컬 칩들과 `[+ 추가]` 버튼만 깔끔하게 노출.
   - `[+ 추가]` 클릭 시 검색 인풋으로 전환되며 하단에 공연 참여자 검색 결과 플로팅 팝업이 표시되어 원하는 멤버를 손쉽게 추가.
6. **참고 링크 및 타임스탬프**:
   - 유튜브 영상 등록 시 레이아웃 순서: **1. 참고 링크 URL → 2. 영상 미리보기 → 3. 타임스탬프 목록/추가 → 4. 설명(메모)**.
   - **타임스탬프 독립 목록 관리**: 타임스탬프는 본문 텍스트에 섞지 않고 각 링크 하위에 독립된 목록(`timestamps: { time, label }[]`)으로 관리되며, 클릭 시 해당 구간으로 즉시 영상이 점프합니다.
   - **영상 재생 중 실시간 캡처 (`[⏱️ 현재 시점 설명 추가]`)**: 유튜브 영상 재생 도중 원하는 구간에서 버튼을 클릭하면 영상이 자동 일시정지(`pauseVideo()`)되고 현재 재생 초가 정확히 캡처되어 타임스탬프 추가 모드로 진입합니다.
   - **비유튜브 링크 예외 처리**: 구글 드라이브, 음원 스트리밍 등 일반 링크는 타임스탬프 기능이 표시되지 않고 외부 링크 카드와 설명 필드만 표시됩니다.
   - **설명/어필 기본 높이 5줄 이상**: 참고 링크 설명 및 곡 추천 어필 텍스트 영역의 기본 높이가 **5줄 이상(`min-h-[130px]`)**으로 넉넉하게 제공됩니다.
7. **작성 중 이탈 방지 (`useUnsavedChangesWarning`)**:
   - 양식 수정 중 [취소], [← 뒤로가기], 상단 로고 및 내부 메뉴 클릭, 브라우저 닫기/새로고침 시 저장되지 않은 변경사항 경고 팝업이 표시됩니다.
   - 제목·아티스트·어필뿐 아니라 악보 상태/메모, 필요 세션, 추천 보컬, 링크 및 타임스탬프 변경도 작성 중 상태로 감지합니다.
8. **권한 검증**: 서버 액션(`addSetlist`)에서 현재 로그인 사용자가 해당 공연의 `performers`에 등록되어 있는지 검증 후 저장.

### 3.3 곡 상세 드로어 (`NominationDrawer`) & 곡 수정 전용 페이지 (`/gigs/[id]/nominations/[songId]/edit`)

- 가능·불가능·미응답 칩은 상태 표시 전용으로, 클릭·터치·hover 시 배경색이 변하지 않습니다.
- 모바일 디자인을 모든 화면 크기에 공통 적용합니다. 미디어 탭은 최대 150px, 세션 버튼은 12px 글자, 응답 현황 제목과 통계는 세로 배치하며 데스크톱 전용 참여자 확인 문구를 표시하지 않습니다. 모바일(640px 미만)은 drawer의 좌우 위치를 화면 끝에 고정하고 최대 너비 제한·왼쪽 테두리·바깥 그림자 없이 불투명 배경으로 화면 전체 폭을 채워 경계나 틈이 비치지 않게 합니다. 640px 이상은 기존 화면 우측 배치와 최대 너비(`max-w-lg`), 왼쪽 테두리·그림자를 유지합니다.
1. 곡 카드를 클릭하면 화면 우측에서 슬라이드 오버 형태로 상세 서랍이 열리고 배경에 블러 딤 처리가 적용됩니다. 서랍이 열려 있는 동안 배경 `body` 스크롤이 고정(`overflow: hidden` 및 스크롤바 너비 보정)되어 이중 스크롤바 노출 및 배경 스크롤 누수가 방지되며, `Escape` 키로 서랍을 닫을 수 있습니다.
2. 정보 배치 순서:
   - **기본 정보 카드**: 타이틀, 아티스트, 추천자, 등록/수정 일시.
   - **미디어 섹션 (유튜브 영상 임베드 & 외부 링크 배너)**:
     - 복수 링크 등록 시 상단 탭(`[▶ 영상 1]`, `[🔗 구글 드라이브]` 등)으로 통합 전환.
     - 유튜브 영상은 16:9 반응형 플레이어, 일반 링크는 서비스 파비콘·뱃지·원클릭 새 탭 열기·복사 기능이 포함된 리치 배너 카드로 렌더링.
     - 링크별 등록된 타임스탬프 점프 칩 및 순수 설명 메모 지원. 유튜브와 일반 외부 링크 설명 모두 입력한 줄바꿈을 보존하며, 말줄임표나 줄 수 제한 없이 전체 내용을 표시하고 긴 텍스트는 영역 폭에 맞춰 줄바꿈합니다.
   - **어필 섹션**: 작성자의 추천 사유 및 특이사항.
   - **섹션 제목 스타일**: 어필·악보·세션·나의 응답 제목은 동일한 12px 크기, 굵은 글자(`font-black`), 자간, 중립 글자색, 14px 아이콘과 아이콘 간격을 사용합니다. 악보는 콜론 없는 독립 제목을 위에 두고 상태 뱃지와 메모를 아래 행에 표시합니다.
   - **악보 상태**: `'악보 있어요'` / `'악보 없어요'` 뱃지 및 작성된 악보 메모를 입력한 줄바꿈과 함께 전체 노출.
   - **세션 섹션**:
     - 필요한 악기 파트별 칩 및 요구 인원수 표시.
     - 추천 보컬은 모든 화면 크기에서 별 아이콘 없이 `추천` 텍스트 배지로 표시합니다. 가능 여부 칩과 같은 높이(`h-6`, 24px)로 텍스트를 가운데 정렬하고 툴팁으로 추천 의미를 제공합니다.
     - **충족 여부 색상 표시**: 가능 인원 >= 요구 인원인 경우 초록색(`emerald`), 가능+미응답 인원 < 요구 인원인 경우 빨간색(`rose`), 그 외 미결정 상태는 기본 중립색.
     - **인라인 세션 응답 현황**: 첫 번째 세션 파트가 기본으로 선택되어 열려있으며, 헤더에 `{세션} 세션 응답 현황` 제목과 함께 `가능 X명`, `불가능 Y명`, `미선택 Z명` 뱃지 노출. 하단 목록은 카드 형태로 참여자(가능 여부 뱃지, 기수+이름, 추천 뱃지[툴팁 및 화면 크기와 무관한 `추천` 텍스트], 세션 chip, 작성된 메모 말풍선)를 노출하며 작성 메모가 없는 경우 공백/placeholder 없이 깔끔하게 생략. 참여자가 많아도 목록 높이 제한과 내부 스크롤 없이 선택된 세션의 모든 응답을 기본적으로 펼쳐 표시하며, 드로어 본문의 공통 스크롤로 탐색. 메모는 참여 회원과 관리자 모두 말줄임표 없이 전체 내용을 확인할 수 있도록 입력한 줄바꿈을 보존하고 긴 텍스트는 카드 폭에 맞춰 줄바꿈.
     - 기본 세션(보컬, 기타, 베이스, 드럼, 건반 및 동의어)은 배정자가 없어도 전체 참여자에게 개방하지 않습니다. 기타 배정자가 없는 경우 건반 등 다른 세션 참여자를 기타 응답 목록이나 충족 인원에 포함하지 않으며, 실제 응답도 없으면 빈 목록을 표시합니다. 기본 세션에 속하지 않고 공연 참여자에게도 배정되지 않은 직접 입력 세션만 전체 참여자에게 개방합니다.
     - 목록과 통계는 현재 공연 세션 배정으로 구성합니다. 기타 응답 기록이 남아 있는 건반 참여자나 공연에서 제외된 사람을 기타 목록에 추가하지 않습니다. 표시 파트 역시 회원 프로필이 아니라 현재 공연 배정을 사용하며, 추천 보컬 예외와 직접 입력 세션의 응답 규칙은 유지합니다.
   - **나의 응답 (`NominationResponseSection`)**:
     - 복잡한 전체 통계를 제거하고 세션과 가능/불가능/미응답 뱃지 및 `[가능 여부 응답]` 버튼을 표시. 단일·복수 세션 모두 작성 메모는 별도 행에 말줄임표 없이 전체 표시하며 입력한 줄바꿈을 보존.
     - 단일·복수 세션 및 배정 세션이 없는 상태 모두 콜론 없는 `나의 응답` 제목과 메시지 아이콘을 응답 카드 위에 표시합니다. 복수 세션은 세션 개수를 함께 표시하며 응답 버튼은 모든 화면 크기에서 drawer 하단 고정 액션 바에 둡니다.
     - 세션 칩은 단일·복수 세션 표시 영역과 응답 입력 모달 모두 응답 현황 목록과 같은 중립색 배경·글자색, 11px 글자, 보통 강조 굵기, 둥근 모서리와 테두리·여백을 사용합니다. 추천·자유 세션 표시는 유지합니다.
     - 나의 저장된 세션 응답 이후 곡이 수정되면 `마지막 응답 이후 글이 수정되었습니다` 안내와 `[응답 다시 확인]` 버튼을 표시합니다. 곡 열람으로 해제되지 않으며 응답 재저장에 성공해야 해제됩니다. 가능 여부 저장 성공/실패 토스트는 하단 중앙에 표시하고 모바일 고정 응답 버튼 위로 간격을 둡니다. [관련 명세](../features/nomination-response-review.md).
     - 단일·복수 세션의 응답 상태 칩과 세션 응답 현황의 상태 칩은 마우스를 올리거나 눌러도 원래의 상태 색상을 유지하며 검은 primary hover 배경으로 변하지 않습니다.
     - 모바일·데스크톱 모두 `[가능 여부 응답]` 버튼을 상세 드로어 하단에 고정 액션 바로 표시하고, 본문이 버튼에 가려지지 않도록 동일한 하단 여백(`pb-28`)과 기기 안전 영역을 적용합니다. 응답 카드 제목 옆의 별도 버튼은 표시하지 않습니다.
3. **수정 및 삭제**:
   - 후보곡 등록자 본인 또는 관리자일 경우 드로어 헤더에 `[수정]` 버튼이 표시됩니다.
   - `[수정]` 버튼 클릭 시 **전용 수정 페이지(`/gigs/[id]/nominations/[songId]/edit`)**로 이동하여 여유로운 화면에서 곡 정보, 세션 파트, 추천 보컬, 영상 링크 및 타임스탬프, 어필을 편집할 수 있습니다.
   - 수정 페이지 하단 좌측에 `[🗑️ 추천곡 삭제하기]` 버튼이 배치되어 있어 안전한 확인 절차 후 곡을 삭제할 수 있습니다. 본인이 아니거나 비인가 사용자의 접근 시 차단 카드를 표시합니다.

## 4. UI 상태 (States)

| 상태 | 화면 표시 및 처리 |
| :--- | :--- |
| **추천 진행 중 (Active)** | 가장 큰 단위로 간략히 표시하는 마감 카운트다운, `후보곡 추천하기` 버튼 활성화 |
| **추천 마감 (Expired)** | `추천곡 접수가 마감되었습니다` 안내 표시, 일반 참여자는 `후보곡 추천하기` 비활성화 (`disabled`), 관리자는 상시 활성화 유지 |
| **곡 없음 (Empty)** | 점선 테두리 카드: `"아직 추천된 곡이 없습니다."` |
| **비참여자 등록 시도** | 에러 알림: `"이 공연의 참여자로 등록되지 않았습니다."` |
