# 04. 선곡 회의 및 셋리스트 페이지 (`/gigs/[id]/setlists`)

## 1. 개요 및 접근 권한
- **URL 경로**: `/gigs/[id]/setlists`
- **대상 사용자**:
  - **조회**: 모든 사용자 (방문자, 일반 회원, 관리자)
  - **곡 등록**: **해당 공연의 참여 세션원(Performer)**
  - **곡 삭제**: 곡 등록 본인 또는 관리자
- **목적**: 특정 공연에서 연주할 후보곡을 등록하고, 필요 세션 파트(보컬, 악기) 및 악보, 유튜브 음원 링크를 공유하며 팀원들과 편성을 조율.

## 3. 사용자 인터랙션 및 UX 흐름 (Step-by-Step)

### 3.1 마감 타이머 계산 (Deadline Timer)
- 회의 일시(`meeting_date`)의 **24시간 전**을 곡 추천 최종 마감 시각으로 자동 계산합니다.
- 마감 전: 남은 일/시간/분이 실시간으로 갱신되며 `[+ 곡 추천하기]` 버튼 활성화.
- 마감 후: `"곡 추천이 마감되었습니다."` 문구로 전환되며 `[+ 곡 추천하기]` 버튼이 비활성화됨.

### 3.2 곡 추천 모달 (`SetlistNewModal`)
1. `[+ 곡 추천하기]` 클릭 시 모달 다이얼로그 표시.
2. 곡 제목, 아티스트 입력.
3. 필요 세션 칩(보컬, 기타, 베이스, 드럼, 건반 등)을 클릭하여 토글 및 인원수 조절.
4. 악보 보유 여부 체크박스 지정.
5. 유튜브 또는 음원 참고 URL 및 링크 메모 추가 (여러 개 등록 가능).
6. 메모/특이사항 작성 후 `[등록]` 클릭.
7. **권한 검증**: 서버 액션(`addSetlist`)에서 현재 로그인 사용자가 해당 공연의 `performers`에 등록되어 있는지 검증 후 저장.

### 3.3 곡 상세 드로어 (`SetlistDrawer`)
1. 곡 카드를 클릭하면 화면 우측에서 슬라이드 오버 형태로 상세 서랍이 열리고 배경에 블러 딤 처리가 적용됩니다.
2. 첨부된 유튜브 링크가 있을 경우 동영상 미리보기 및 링크 재생 제공.
3. 본인이 등록한 곡이거나 관리자인 경우 하단에 `[곡 삭제]` 버튼 노출.

## 4. UI 상태 (States)

| 상태 | 화면 표시 및 처리 |
| :--- | :--- |
| **추천 진행 중 (Active)** | 마감 카운트다운 표시, `곡 추천하기` 버튼 활성화 |
| **추천 마감 (Expired)** | 마감 안내 표시, `곡 추천하기` 버튼 비활성화 (`disabled`) |
| **곡 없음 (Empty)** | 점선 테두리 카드: `"아직 추천된 곡이 없습니다."` |
| **비참여자 등록 시도** | 에러 알림: `"이 공연의 참여자로 등록되지 않았습니다."` |
