# 09. 갤러리 사진첩 페이지 (`/photos`)

## 1. 개요 및 접근 권한
- **URL 경로**: `/photos`
- **대상 사용자**:
  - **조회**: 모든 사용자 (방문자, 회원, 관리자)
  - **사진 등록/수정/삭제**: **관리자(Admin) 전용**
- **목적**: 정기 공연, 버스킹, 합주실 연습 등 동아리 활동 사진을 시각적으로 전시하고 관리.

## 3. 사용자 인터랙션 및 UX 흐름

1. **라이트박스 풀사이즈 뷰어**:
   - 사진 카드 클릭 시 화면 전체를 덮는 라이트박스 모달이 열리며 원본 고화질 이미지와 상세 캡션을 확인 가능.
2. **관리자 사진 관리**:
   - `[+ 사진 등록]` 클릭 시 모달 오픈: 이미지 URL, 제목, 상세 캡션 입력 후 `addPhotoAction` 호출.
   - 각 사진 수정/삭제 시 `updatePhotoAction`, `deletePhotoAction`을 실행하여 실시간 반영.
