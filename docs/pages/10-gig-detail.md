# 10. 공연 상세 정보 페이지 (`/gigs/[id]`)

## 1. 개요 및 접근 권한
- **URL 경로**: `/gigs/[id]` (예: `/gigs/2`)
- **대상 사용자**: 모든 사용자 (비회원 방문자, 일반 부원, 관리자)
- **목적**:
  - 공연 공식 일정, 진행 상태, 대형 포스터, 확정된 정식 SETLIST(곡명, 아티스트, 연주자 명단), 프로필 사진 위주의 공연자 명단을 표시.
  - 로그인 부원에게는 상단 액션 바에서 선곡 회의(`/gigs/[id]/setlists`)로 즉시 이동할 수 있는 바로가기 제공.
  - 관리자에게는 상단 액션 바에서 `공연 수정`(`/gigs/[id]/edit`) 및 `참가 신청 링크 복사` 버튼 제공.

## 3. 주요 구성 및 UX 흐름

1. **상단 액션 바**:
   - `[← 공연 목록으로]` 뒤로가기
   - 우측 액션 버튼:
     - `선곡 회의 바로가기`: 로그인 회원 전용 (히어로 내부에서 상단으로 이동)
     - `공연 수정`: 관리자 전용 (`/gigs/:id/edit`)
     - `참가 신청 링크 복사`: 관리자 전용
2. **히어로 섹션 (Hero Section)**:
   - 포스터 이미지를 대폭 확대(`w-56 sm:w-72 md:w-80`)하여 시각적 몰입감 제공.
   - SOKNA LIVE ARCHIVE 문구 및 부제목 삭제.
   - 주요 정보를 **세로 2행(1행: 공연 일시, 2행: 공연 장소)**으로 깔끔하게 배치 (참여 세션 카드 삭제).
3. **SETLIST 섹션 (1순위)**:
   - 트랙 번호 배지(`#1`), 곡 제목, 아티스트, 그리고 **해당 곡 연주자 명단(`session_members`)**을 정돈된 리스트로 노출.
4. **공연자 섹션 (2순위)**:
   - 세로로 긴 직사각형 카드 형태(`grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5`).
   - 프로필 사진: **3:4 비율의 모서리가 둥근 직사각형**(`rounded-xl aspect-[3/4] object-cover`).
   - 각 카드마다 이번 공연 기준 배정된 세션(파트) 배지 및 기수 표기.
   - **공연별 프로필 사진 업로드**: **관리자** 또는 **해당 공연자 본인(`p.user_id === currentUserId`)**에게 카메라 버튼이 노출되어, 공연 상세 페이지에서 바로 프로필 사진을 등록/변경 가능 (`updatePerformerPhoto`).
