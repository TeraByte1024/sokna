# 10. 공연 상세 정보 페이지 (`/gigs/[id]`)

## 1. 개요 및 접근 권한
- **URL 경로**: `/gigs/[id]` (예: `/gigs/2`)
- **대상 사용자**: 모든 사용자 (비회원 방문자, 일반 부원, 관리자)
- **목적**:
  - 공연 공식 일정, 진행 상태, 대형 포스터, 확정된 정식 SETLIST(곡명, 아티스트, 연주자 명단), 프로필 사진 위주의 공연자 명단을 표시.
  - 히어로 섹션과 모바일 하단 플로팅 바에서 `공연 참가`(`/gigs/[id]/join`) 및 `선곡회의`(`/gigs/[id]/nominations`)로 즉시 이동할 수 있는 핵심 CTA 제공.
  - 상단 액션 바에서 `공연 공유`(Web Share API 및 클립보드 복사) 및 관리자용 `공연 수정`(`/gigs/[id]/edit`) 버튼 제공.

## 3. 주요 구성 및 UX 흐름

- **로딩 상태**: 상단 액션 바, 포스터와 공연 정보가 나란히 놓인 히어로, 아래 정보 카드의 스켈레톤을 표시합니다. 스크린리더에는 로딩 문구를 알리고 움직임 줄이기 설정 시 점멸을 멈춥니다.
- **조회 순서**: 공연 기본 정보는 메타데이터와 본문에서 요청 단위로 재사용하고, 관리자 여부·로그인 상태와 병렬로 확인합니다. 접근 권한 확인 뒤 공연자와 확정 셋리스트를 병렬 조회합니다.
- **이미지**: Supabase 공개 Storage의 포스터·공연자 사진은 화면 크기에 맞춰 최적화하며, 외부 이미지 URL은 직접 표시합니다. 첫 포스터를 우선 로드하고 나머지 사진은 지연 로드합니다.

1. **상단 액션 바**:
   - `[← 공연 목록으로]` 뒤로가기
   - `[공연 공유]` (`ShareGigButton`): 모바일 Web Share API 지원 시 시스템/카카오톡 공유 시트 호출, 미지원/PC 환경에서는 클립보드 복사 처리
   - `[공연 수정]`: 관리자 전용 (`/gigs/:id/edit`)
2. **히어로 섹션 (Hero Section - 메인 CTA)**:
   - 포스터 이미지를 대폭 확대하고, 데스크톱에서 우측 `[공연 참여] | [선곡회의]` 버튼 하단 라인까지 포스터 높이가 자연스럽게 일치하도록 정렬(`md:items-stretch`, `md:self-stretch`).
   - 주요 정보를 **세로 2~3행**으로 깔끔하게 배치 (선곡회의 정보는 다이얼로그에만 집중 노출):
     - 1행: 일시 (`formatKoreanDateTime(gig.perform_date, gig.perform_time)`, 지난 공연인 경우 일시 맨 앞에 `[종료]` 뱃지 표시)
     - 2행: 장소 (`gig.location || "공연 장소 미정"`)
     - 3행: 티켓 예매 정보 (사전예매 / 현장구매 가격이 등록된 경우 노출, 예: `사전예매 5,000원 · 현장구매 7,000원`)
   - **핵심 CTA 2종 (방안 1 - `GigDetailActions`)**:
     - **비회원(로그아웃 상태) 처리**: 비회원 방문자에게는 공연 참여 및 선곡회의 권한이 없으므로 히어로 섹션과 모바일 하단 플로팅 바의 `[공연 참여]` / `[선곡회의]` 버튼을 렌더링하지 않습니다 (`isLoggedIn` 기준 가드).
     - `[공연 참여]`: 회원 로그인 시 노출. 클릭 시 참여 모달 다이얼로그(`GigJoinDialog`) 오픈. 버튼 좌측에 `{내 참여 여부 아이콘}`(참여: 초록 체크, 불참: 빨간 X, 미정: 주황 물음표, 미신청: 기본 유저 아이콘)을 동적으로 표시하고 `공연 참여` 단일 텍스트 제공.
     - `[선곡회의]`: 회원 로그인 시 노출. Secondary 버튼으로 `/gigs/[id]/nominations` 이동
3. **공연 참여 다이얼로그 (`GigJoinDialog`)**:
   - 다이얼로그 제목: `공연 참여`
   - 포스터를 제외한 공연 기본 정보(제목, 부제목, 공연 일시 및 시각, 공연 장소)와 선곡회의 정보(회의 일시 및 시각, 회의 장소)를 카드 형태로 요약 표시.
   - 참여 여부 선택: `참여`(초록색 강조), `불참`(붉은색), `미정`(주황색).
   - 세션 선택: 표준 세션(`보컬(남)`, `보컬(여)`, `기타`, `베이스`, `키보드`, `드럼`) 칩 선택 방식.
   - 비고: 늦참/불참 예정 등 특이사항 작성 필드 제공.
   - 하단 액션 버튼: 취소 및 `[저장]` 버튼 (신청/수정 공통)
   - 비로그인 유저에게는 로그인 유도 화면 및 로그인 버튼 제공.
   - `/gigs/[id]/join` 접근 시 `/gigs/[id]?join=true`로 리다이렉트되어 자동으로 모달이 팝업됨.
4. **모바일 하단 플로팅 바 (방안 3)**:
   - 로그인된 회원에게만 작은 화면(`sm:hidden`)에서 화면 하단에 `[공연 참여]`, `[선곡회의]` 버튼을 고정 노출하여 스크롤 중에도 언제든지 핵심 액션 진입 가능 (`GigDetailActions`). 비회원에게는 하단 바가 렌더링되지 않으며 바닥 여백 또한 컴팩트하게 조정됩니다.
5. **SETLIST 섹션 (1순위)**:
   - 칩으로 감싸지 않은 트랙 번호 텍스트(`#1`), 곡 제목, 아티스트, 그리고 **해당 곡 연주자 명단(`session_members`)**을 정돈된 칩(`[세션명 이름]`) 형태로 노출. 한 세션에 여러 연주자가 있어도 이름 사이에 쉼표를 사용하지 않으며, 세션별 인원수 숫자 뱃지 없이 순수 세션명과 배정된 연주자 이름만 깔끔하게 표시됩니다.
6. **LINEUP 섹션 (2순위)**:
   - 세로로 긴 직사각형 카드 형태(`grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5`).
   - 프로필 사진: **3:4 비율의 모서리가 둥근 직사각형**(`rounded-xl aspect-[3/4] object-cover`).
   - 각 카드마다 이번 공연 기준 배정된 세션(파트) 배지 및 기수 표기.
   - **프로필 사진 수정 권한**:
     - **일반 참여자**: 로그인한 본인의 카드(`p.user_id === currentUserId`)에만 `[나]` 식별 배지와 함께 사진 등록/변경/삭제 버튼이 노출되며, **오직 자신의 프로필 사진만을 수정/삭제**할 수 있습니다 (타 참여자 카드에는 수정 버튼 미노출 및 서버 액션 차단).
     - **관리자(Admin)**: 모든 참여자 카드에 사진 등록/변경/삭제 버튼이 노출되어 일괄 관리할 수 있습니다 (`updatePerformerPhoto`).
