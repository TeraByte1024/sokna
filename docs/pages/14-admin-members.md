# 14. 회원(관리자) 관리 (`/admin/members`)

## 접근과 목적

- 관리자 전용. 검증된 Auth 사용자 ID가 `admins.id`에 있을 때만 공통 관리자 레이아웃과 이 화면에 접근한다.
- 승인된 정식 회원 목록과 관리자 명단을 확인하고 회원 정보 및 권한을 관리한다.
- 가입·공연 신청 승인은 [가입/공연 신청 승인](./15-admin-approvals.md) 화면에서 처리한다.

## 회원 목록

- 기본 목록은 `users.status = 'approved'`이다. 이름·이메일·기수·세션 통합 검색, 기수·세션·관리자 여부 필터를 제공한다.
- 기수 높은 순/낮은 순, 이름순, 최근/오래된 승인순으로 정렬한다. 검색 결과 수와 빈 결과 안내를 표시한다.
- 이름·기수·세션 수정은 `updateMemberByAdminAction`을 사용한다. 입력 중 이탈 시 `LeaveConfirmDialog`로 확인한다.

## 관리자 권한

- `admins.id`와 회원 ID를 비교하여 관리자 여부를 표시한다. 이메일은 표시·임명에만 사용한다.
- 승인 회원에게 `grantAdminAction`으로 관리자 권한을 부여하고, 관리자 명단에서 `revokeAdminAction`으로 권한을 회수한다.
- 대상 확인 후 실행한다. 이메일이 없는 회원은 임명할 수 없고, 마지막 관리자 및 본인 권한은 회수할 수 없다.

## 화면 상태와 데이터

- 명단 조회 오류, 필터 결과 없음, 권한 처리 오류를 각각 표시한다. 처리 중 중복 실행을 막는다.
- 좁은 화면의 표는 가로 스크롤하며 공통 관리자 메뉴·제목·요약 수치·표 스타일을 사용한다.
- 화면: `app/admin/members/page.tsx`, `member-management-client.tsx`. 액션: `app/admin/members/actions.ts`.
