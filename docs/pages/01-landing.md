# 01. 메인 랜딩 페이지 (`/`)

## 1. 개요 및 접근 권한
- **URL 경로**: `/`
- **대상 사용자**: 모든 사용자 (방문자, 일반 회원, 관리자)
- **목적**: 동아리(소리로 크는 나무)의 아이덴티티와 주요 활동(공연, 정기 모임, 친목)을 시각적으로 전달하고, 공연 정보 및 로그인/회원가입으로 연결하는 진입점.

## 3. 사용자 인터랙션 및 UX 흐름 (User Interactions)

1. **초기 로드 (First Impression)**:
   - 다크 테마 기반의 히어로 섹션에서 클럽 로고와 타이틀이 위로 서서히 떠오르는 페이드인 애니메이션 실행 (`framer-motion`, 1.5초).
   - 하단 스크롤 인디케이터가 깜빡이며 사용자의 스크롤을 유도.
2. **40주년 기념 배너 (Anniversary CTA)**:
   - 히어로 섹션 하단에 40주년 기념 공연 안내 배너 배치.
   - 클릭 시 `/40th-anniversary` 페이지로 이동.
   - CTA 버튼: `🎂 40주년 행사 바로가기` (생일 케이크 이모지 및 호버 글로우 효과).
3. **스크롤 패럴랙스 (Storytelling)**:
   - 스크롤을 내리면 3개의 테마 섹션(공연, 모임, 친목)이 전환되며 배경 이미지와 감성적인 카피라이트 노출.
4. **네비게이션 이동**:
   - 상단 헤더:
     - **데스크톱 (`md:` 이상)**: `공연`(/gigs), `역사`(/history), `부원`(/members), `갤러리`(/photos), 그리고 골드 하이라이트된 `🎂 40주년`(/40th-anniversary) 링크 전체 인라인 노출.
     - **모바일/태블릿 (`md:` 미만)**: 폭 부족 시 레이아웃 보호를 위해 **로고 왼쪽에 'v' 형태의 expand 버튼**(`ChevronDown`) 제공. `공연`과 `🎂 40주년`은 상시 노출되며, `역사`, `부원`, `갤러리`는 expand 버튼 클릭 시 플로팅(float) 형태가 아닌 **상단 헤더가 아래로 부드럽게 확장(Accordion)**되며 하단 서브 메뉴 바로 노출됨.
   - 비로그인 상태: `회원 로그인` 버튼 클릭 시 `/auth/login`으로 이동 (처음 방문자는 로그인 화면에서 회원가입 신청으로 유도).
   - 로그인 상태: 프로필 아이콘 버튼이 노출되며, 클릭 시 플로팅(float) 드롭다운으로 `내 정보`, `로그아웃` 2개 메뉴가 표시됨 (관리자인 경우 `회원 관리` 바로가기 버튼 동시 노출).

---

## 4. UI 상태 (States)

- **비로그인 상태 (Default)**:
  - 헤더 우측에 단일 `회원 로그인` 버튼 표시.
- **로그인 상태**:
  - 헤더 우측에 프로필 아이콘(클릭 시 플로팅 드롭다운: `내 정보` / `로그아웃`) 및 관리자 바로가기(관리자 전용) 표시.
