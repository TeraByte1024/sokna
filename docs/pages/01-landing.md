# 01. 메인 랜딩 페이지 (`/`)

## 1. 개요 및 접근 권한

- **URL 경로**: `/`
- **대상 사용자**: 모든 사용자(방문자, 일반 회원, 관리자)
- **현재 상태**: 정식 소개 콘텐츠 제작 전 임시 랜딩 페이지
- **목적**: 사이트가 개발 중임을 명확히 안내하면서 사용 가능한 공연 정보와 로그인 화면으로 연결합니다.

---

## 2. 현재 임시 화면 구성

```text
+-------------------------------------------------------------------+
| [SOKNA Logo]    [공연]                                  [로그인] |
+-------------------------------------------------------------------+
|                                                                   |
| [LANDING PAGE IN PROGRESS]       +-----------------------------+  |
|                                   | SOKNA / BUILDING            |  |
| 새로운 첫 화면을                 | [Logo] 페이지 조율 중       |  |
| 준비하고 있습니다.               | 정식 소개 페이지 구성 중    |  |
|                                   | 공연 정보                   |  |
| 동아리 소개와 활동 기록을         | 선곡 회의                    |  |
| 준비하고 있다는 안내             | 계속 업데이트 중            |  |
|                                   +-----------------------------+  |
| [공연 둘러보기] [회원 로그인]                                    |
| ● 주요 서비스는 이용 가능합니다                                 |
|                                                                   |
+-------------------------------------------------------------------+
```

### 2.1 히어로 안내

- `LANDING PAGE IN PROGRESS` 상태 배지와 공사 중 아이콘을 표시합니다.
- `새로운 첫 화면을 준비하고 있습니다.`라는 핵심 메시지로 임시 페이지임을 안내합니다.
- 배경은 외부 이미지 없이 그리드 패턴과 violet/sky 계열의 은은한 블러 효과로 구성합니다.
- 라이트/다크 테마와 모바일·데스크톱 반응형 레이아웃을 모두 지원합니다.

### 2.2 주요 이동 버튼

- `[공연 둘러보기]`: `/gigs`로 이동합니다.
- `[회원 로그인]`: `/auth/login`으로 이동합니다.
- 상단 헤더 및 공통 푸터는 기존 `SiteLayout`을 그대로 사용합니다.

### 2.3 개발 상태 카드

- 우측 카드에는 과도한 애니메이션 없이 정적인 개발 상태 안내와 다음 항목을 표시합니다.
  - 공연 정보
  - 선곡 회의
  - 계속 업데이트 중
- 화면 진입 시에만 짧은 페이드 애니메이션을 사용하며 반복 애니메이션은 표시하지 않습니다.

---

## 3. 향후 전환 원칙

- 동아리 소개, 활동 사진 및 정식 홍보 콘텐츠가 확정되면 현재 임시 랜딩을 정식 랜딩으로 교체합니다.
- 공연 및 인증 기능의 경로는 정식 랜딩에서도 유지합니다.
- 정식 콘텐츠 적용 전까지 외부 임시 이미지에 의존하지 않습니다.
